# Orion RU — Vencord

![Версия](https://img.shields.io/badge/v4.11.5--ru.1-5865F2)

Русский форк [nyxxbit/discord-quest-completer](https://github.com/nyxxbit/discord-quest-completer). Исходный движок сохранён; добавлены окно внутри Vencord, кнопка в верхней панели Discord и русские настройки.

## Интерфейс

- Кнопка с молнией находится в верхней панели, перед входящими уведомлениями.
- Нажатие показывает и скрывает окно Orion. Закрытие окна не останавливает очередь.
- В окне: список заданий, статусы и прогресс, журнал событий, кнопки «Запустить», «Пауза», «Продолжить», «Стоп», настройки и переход к заданиям Discord.
- Шестерёнка открывает русские настройки прямо в панели; значения сохраняются сразу. В списке плагинов Vencord доступны те же настройки.
- Сочетание **Shift + .** переключает окно вне полей ввода; **Escape** скрывает его.
- Настройки Vencord и сообщения команды `/orion` переведены на русский. Имена игр, идентификаторы команд и технические коды сохраняются.
- Автозапуск выключен по умолчанию. Нажатие кнопки в верхней панели только открывает окно, не принимает задания и не запрашивает награды.
- «Открыть задание» ведёт в штатный раздел Discord для ручных действий.

В проекте есть и отдельный `index.js`; его визуальные элементы также переведены. Основной вариант этого форка — нативный Vencord-плагин.

## Установка в Vencord

Нужна сборка Vencord из исходников с пользовательскими плагинами. Официальная готовая сборка не подгружает произвольные плагины из папки AppData.

```sh
# Внутри исходников Vencord:
git clone https://github.com/DarkAssassin48/discord-quest-completer src/userplugins/orionQuests
pnpm install --frozen-lockfile
pnpm build --dev
pnpm inject
```

После перезапуска включите **OrionQuests** в списке плагинов. Откройте окно кнопкой с молнией. Для обновления выполните `git pull` в папке плагина и пересоберите Vencord.

Разработка: [инструкция исходного плагина](docs/VENCORD-PLUGIN.md). Проверки чистой логики: `pnpm exec tsx --test src/userplugins/orionQuests/tests/*.test.ts` из Vencord. Проверка окна не требует запуска заданий или выдачи доступа OAuth.

## Ограничения исходного проекта

Orion автоматизирует действия учётной записи. Discord может ограничивать задания и аккаунты за такую автоматизацию. Перевод интерфейса, новая кнопка и Vencord не устраняют этот риск. Автозапуск, обработка достижений с OAuth и автоматическое получение наград по умолчанию выключены. Капча и проверка возраста проходятся пользователем в самом Discord; плагин их не решает.

Подробности поведения, совместимости и ограничений: [исходное описание](UPSTREAM.md). Форк не добавляет механизмов обхода обнаружения и не обещает защиту от ограничений.
